# 🎓 Engenharia de Software — 3º Semestre

Repositório dedicado ao armazenamento e versionamento de todos os projetos, trabalhos e laboratórios práticos desenvolvidos durante o **Terceiro Semestre** do curso de Engenharia de Computação (PUC-Campinas).

---

## 📚 Disciplinas Cursadas

Neste repositório, você encontrará diretórios organizados por matéria, refletindo a jornada de aprendizado do semestre atual:

- **📱 Tecnologia e Programação para Dispositivos Móveis** (`EngSfw-Mobile-2026-Flutter/`)
  Desenvolvimento nativo e híbrido, arquitetura de aplicações mobile, design de interfaces (UI/UX) focadas na experiência do usuário e integração de sistemas em ecossistemas portáteis.

- **⚙️ Arquitetura e Organização de Computadores** (`ArqOrgComputadores-2026-MIPS/`)
  Estudo do datapath e da unidade de controle de um processador MIPS single-cycle, álgebra booleana aplicada a circuitos digitais, hierarquia de memória (cache direta, associativa por conjuntos e totalmente associativa) e representação numérica em binário/hexadecimal. Inclui um **simulador de datapath MIPS implementado em Python**, com assembler próprio e trace ciclo a ciclo dos sinais de controle.

*(Outras disciplinas deste semestre serão adicionadas de forma contínua conforme o avanço do curso).*

---

## 🛠️ Tecnologias Utilizadas

- **Ecossistema Mobile:** React Native, Flutter, Android Nativo (Java/Kotlin)
- **Arquitetura de Computadores:** MIPS Assembly, Python (simulação de datapath)
- **Ferramentas:** Android Studio, Git, VS Code
